# Series Memory - Leela.exe

## Core Series Format
Leela.exe is a ten-chapter Dashavatar manga.

Series rules:
1. One Dashavatar per chapter.
2. One chapter per Dashavatar.
3. Each chapter is exactly 10 pages.
4. Each chapter must complete that avatar's essential storyline within those 10 pages.
5. Cross-chapter continuity comes from Vishnu, Dharma instability, recurring motifs, and cosmic consequence, not from unfinished avatar plots.

## Cross-Chapter Continuity Anchors
- Vishnu remains the same underlying preserver consciousness across all avatars.
- Dharma instability evolves across the cycle, even though each chapter is self-contained.
- Visual motifs should recur: water, lotus geometry, stars, reflections, concentric ripples, sacred light.
- Each avatar should feel like a different answer to collapse, not a repeated template.
