# Workflow - analyze_continuity

## Purpose
Review a generated page as a continuity editor and production director.

## Check Categories
1. character model consistency
2. costume and prop continuity
3. environment and weather continuity
4. emotional progression
5. chapter pacing alignment
6. mythology respect
7. style drift

## Required Output
- approval or revision recommendation
- concrete findings
- correction suggestions
- carry-forward updates for chapter memory

## High-Priority Questions
- does the page still look like the same manga?
- does it preserve what the last approved page established?
- does it move the chapter toward closure on page 10?
