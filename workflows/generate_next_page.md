# Workflow - generate_next_page

## Purpose
Generate the next page blueprint and final prompt while preserving continuity.

## Read First
1. `continuity/chapter_memory.md`
2. `continuity/series_memory.md`
3. relevant character files
4. relevant style files
5. relevant lore files
6. latest page review notes

## Required Output Sections
1. Page Objective
2. Panel Breakdown
3. Emotional Direction
4. Continuity Safeguards
5. Final AI Image-Generation Prompt

## Decision Checks
- how many pages remain in the chapter?
- what still needs to happen before page 10?
- is this page escalating, breathing, or resolving?
- what visual facts must carry forward exactly?

## Failure Modes To Avoid
- repeating the previous page beat
- introducing lore that contradicts canon
- changing facial or costume identity
- using admin-space UI in mortal-world scenes without reason
