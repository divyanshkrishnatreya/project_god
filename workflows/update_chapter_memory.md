# Workflow - update_chapter_memory

## Purpose
Update the active chapter after a page is approved.

## Must Be Recorded
- page status
- page objective
- final beat
- emotional progression
- physical continuity changes
- weather and lighting changes
- props now in play
- revealed knowledge
- next-page safeguards

## Update Targets
- `continuity/chapter_memory.md`
- chapter page review file
- `references/reference_index.md` if new canon imagery is locked

## Rule
Do not generate another page until the chapter memory reflects the current approved state.
