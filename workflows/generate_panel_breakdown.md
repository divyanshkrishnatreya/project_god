# Workflow - generate_panel_breakdown

## Purpose
Create a pacing-aware panel map before the final page prompt is written.

## Inputs
- page number
- chapter role of the page
- emotional target
- continuity constraints
- remaining page budget

## Output Per Panel
- shot type
- subject
- action
- emotional beat
- continuity note

## Rule
The panel map should create readable visual rhythm and should never waste page space in a 10-page chapter.
