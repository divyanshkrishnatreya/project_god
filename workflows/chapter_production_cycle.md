# Chapter Production Cycle - Leela.exe

## Purpose
This workflow governs the full life of a 10-page avatar chapter.

## Chapter Lifecycle
1. Lock chapter thesis.
2. Lock avatar-specific chapter objective.
3. Build 10-page pacing map.
4. Produce pages one at a time using the page production cycle.
5. Review each page before proceeding.
6. Re-check remaining page budget after every approval.
7. Ensure the avatar's main conflict is fully resolved by page 10.
8. Write chapter closeout notes and carry forward only series-level consequences.

## Chapter Rules
1. Each chapter is exactly 10 pages.
2. Each chapter belongs to one avatar only.
3. The avatar storyline must resolve inside that chapter.
4. The next chapter begins a new avatar cycle, not unfinished cleanup from the prior one.

## End-Of-Chapter Outputs
- approved page sequence
- final chapter continuity summary
- chapter-level reference assets
- animation adaptation notes if requested
- any series-level continuity update that affects later avatars
